# Diary 1.2.0 更新记录

日期：2026-11-18。平台：Apple 芯片 macOS。

## 新功能

- 设置页面增加“帮助 → 打开使用说明”。弹出的说明书按章节介绍首次选文件夹、三区布局、编辑与保存、标签和分支、相邻日记、附件、外观、删除、备份与安装更新。
- 说明书支持章节导航、Esc 与关闭按钮、点击背景关闭，以及关闭后返回原按钮。小窗口中目录和正文分别滚动。
- 应用直接打包 `docs/Diary-User-Guide.md`。后续用户可见功能的调整应同步维护这份文档，项目 `AGENTS.md` 已写入发布前核对要求。
- 设置页的“返回上一页面”现在会关闭设置，不会暗中改变日记/标签的导航历史。

## 代码结构

- 标签页的外部链接打开方式由组合根注入；标签显隐对象也由组合根创建。日记与标签界面共用独立于应用外壳的导航接口。
- 标签索引通过显隐策略接口查询分组。其余审查建议的取舍见 [架构审查处理记录](./Review-2026-11-18.md)。
