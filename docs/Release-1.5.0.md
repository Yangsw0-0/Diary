# Diary 1.5.0

发布日期：2026-11-21

## 本版内容

1.5.0 按手绘稿重做「节点」画布：

- **时间轴**：日期与事件标题分列轴线上下并按节点交替排布，引线连接小圆点；聚焦节点以事件颜色填充圆点并加光晕。隐藏滚动条，左右拖动/横向滑动后把最近事件吸附到中央，与下方轮盘指针双向对齐。最早端显示「起点」，最新端显示箭头与「to be continue…」；时间轴与轮盘之间增加细分隔线，两端渐隐。
- **轮盘**：事件卡片取消显式边框，改用沿正方向长、垂直方向短的径向遮罩形成笔刷色块；卡片内按「日期 · 分隔符 · 事件标题 · 分隔符 · 六个色块」排列，分隔符为上下短线夹圆点，色块改为手绘感形状并只在聚焦/悬停时显示。新增长指针和实线/虚线圆环装饰，卡片仍随轮盘旋转。
- **修复**：离开节点页时保存失败不再静默；拖动后首次点击色块/铅笔不再被吞；`pointerup` 使用最新位置；色块与删除异常会提示；`reset` 清理保存状态；覆盖保存可排队执行；损坏 JSON 与非法日期显示中文错误；节点文件位于 OneDrive 等重解析点目录时不再被误拒；备份在硬链接不可用时回退重命名。懒加载画布并支持注入仓库，补充相关测试。

macOS 与 Windows 使用同一套节点数据和交互，差异仅限平台打开方式与打包配置；详见[平台支持与源码分区](./Platform-Support.md)。
