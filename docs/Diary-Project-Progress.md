## 测试资料与风险

- 测试夹具放在 `tests/fixtures/`，只使用人工编写的示例 Markdown，不复制真实日记。
- 文件测试用临时目录，重点检查非法日期、路径逃逸、写入失败、revision 冲突和残留临时文件。
- UI 测试重点是中文输入法、连续保存、关闭前草稿、原位渲染、历史导航和滚动恢复。
- 附件测试重点是同名文件、复制失败、图片预览、普通附件及整目录迁移。
- 旧文件格式与同日期冲突待脱敏样例确定；附件类型和大小限制待实测后明确。
- GitHub 只管理程序代码和文档；日记根目录需要单独备份。
