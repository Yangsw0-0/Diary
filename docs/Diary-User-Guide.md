# Diary 使用说明

这份说明介绍 Diary 的基础操作。可以从“设置 → 帮助”随时重新打开。

## 开始使用

1. 首次启动时，点击“选择文件夹”，选择一个**已经存在**的日记根文件夹。应用不会自动创建或预选文件夹；取消后可以稍后再选。
2. 以后打开应用会继续使用上次选择的文件夹。若文件夹移动、被删除或不可读写，应用会提示重新选择。
3. 左侧“日记”用于按日期写作；“标签”用于汇集同一主题；左下角“设置”用于更换文件夹和调整外观。

日记只保存在你选择的文件夹中。GitHub 上的程序源码和安装包不会自动备份日记。

## 界面与布局

- **功能侧栏**在最左侧，可切换日记、标签和设置。拖动其右边缘可调整宽度；右下角按钮可收起，收起后鼠标移到窗口左边缘可临时唤出。
- 左下角的**写作统计**显示当前文件夹已记录的日期数与累计字数。字数只统计已保存日记中可见的非空白字符，包含标点，不计 Markdown 符号、首行日期和图片路径；未保存草稿不计入。文件载入失败时会提示有文件未计入。
- **列表栏**在中间：日记模式显示日期和当天的标签，标签模式显示主标签。拖动中右之间的分隔条可调整列表宽度；列表右下角按钮可收起列表。
- **内容栏**在右侧：显示日记编辑器或只读的标签详情。三个区域各自滚动，不会一起移动。
- 顶部的“返回上一页面”“返回下一页面”可以在日记与标签之间往返，并恢复此前阅读位置。在设置页点击“返回上一页面”会先关闭设置，回到进入设置前的页面；导航历史仅在本次运行期间保留。

## 写日记与保存

1. 在“日记”中点击中间列表的日期以打开当天内容；点击“新建”可创建今天的日记。
2. 直接在右侧正文画布编辑。编辑时能看到标题、列表等 Markdown 内容的渲染效果；修改会保存回当天的 Markdown 文件。
3. 停止输入约 800 毫秒后应用自动保存。内容栏顶部的圆形指示灯始终可见：绿色表示已保存、黄色表示尚未保存，灰色表示正在保存、红色表示保存失败。点击指示灯或按 **⌘S**（macOS）/ **Ctrl+S**（Windows）可手动保存；鼠标停在指示灯上可查看状态文字。
4. 修改正文首行日期并保存时，应用会按新日期改名并移至对应年份文件夹；如果目标日期已有文件，会保留当前草稿并提示冲突。
5. 保存失败时，不要直接关闭窗口。右侧会保留草稿并提供重试保存、重新加载磁盘版本、确认覆盖或放弃草稿等操作。切换文件夹、离开日记或关闭应用前也会检查未保存的内容。

编辑正文时，段落左侧的“+”与拖动按钮会随正文缩放调整大小；内容栏较窄时，它们会在左侧留白中纵向排列，避免盖住正文。在段落中右键可打开“插入插件”菜单，选择图片或附件、分隔线、代码块或表格。插入位置是右键所点的段落。

日记列表的每个条目显示日期和当天的主标签，用 `·` 分隔。`探索自我 - 恋爱` 只显示 `探索自我`；同一天重复的主标签只显示一次。内容过长时会在列表宽度内省略；正文不会因此被截断。

## 标签与分支

在日记中用二级标题写标签，例如：

```markdown
## 探索自我 - 恋爱

今天想到的事情……

## 探索自我 - 世界观

另一段记录……
```

- `探索自我` 是**主标签**，`恋爱` 和 `世界观` 是可选的**分支**。连字符两侧留空格；不写 ` - 分支` 时，整个标题就是主标签。
- “标签”列表按主标签归类；右侧每段内容顶部显示原日记日期，右上角显示分支。点击日期可跳回原日记编辑；标签详情本身不能直接编辑。
- 标签默认在出现两天及以上时显示在上方，只出现一天的标签默认归入“隐藏的标签”。右键标签可手动“显示”或“隐藏”。两个分区都先按出现天数、再按最近出现日期排序。
- 输入 `## ` 并键入标签前缀后，光标后可能出现浅色补全。按 **Tab** 接受，按 **Esc** 取消；补全提示本身不会写入日记。

## 阅读相邻日记

正文尚未到边界时，触控板和鼠标滚轮只滚动正文。到达边界后继续同方向滚动，先拉出一小段弹性反馈；若继续滑动，相邻日记的只读预览便沿同一轨道进入内容栏。macOS 触控板会跟随手指保持拉拽位置，松手时未达到阈值才回弹，达到阈值则平滑完成一屏切换。鼠标滚轮以短暂停顿作为手势结束。向上翻页落在目标日记结尾，向下翻页落在目标日记开头。每次手势最多切换一篇，切换前仍会检查和保存当前草稿；保存或打开失败会退回原日记。

中间列表的选中背景会随当前日期移动。若系统启用了“减少动态效果”，部分过渡动画会关闭。

## 附件与图片

- 点击右上角“附件”选择文件；也可将文件拖入编辑器，或直接粘贴图片。
- 单个附件须非空且不超过 **20 MiB**。图片可在编辑器和标签详情中预览；其他文件可点击相对链接，由系统打开。
- 附件先复制到日记根文件夹的 `assets/` 下，再把相对链接插入日记。删除正文中的链接**不会**自动删除附件文件。

## 外观与阅读控制

- 在“设置 → 个性化”中选择浅色或深色模式，再选绿色、浅粉色、浅蓝色或使用调色盘自选主题色。
- “列表栏色调”单独决定中间栏的底色；深色模式会用所选颜色调出较暗的底色。
- “设置 → 编辑与阅读 → 正文排版”可调整行间距和字间距，也可一键重置。这些设置只改变显示，不修改 Markdown 文件。
- 在内容栏右下角附近移动鼠标，可唤出视图控制条。用滑块或加减按钮调整正文大小，范围为 **50%–150%**；“展开”按钮让当前内容栏暂时占满应用窗口。
- 日记和标签内容分别记住本次运行中的缩放值。缩放只改变显示，不修改 Markdown 正文。

## 文件、删除与备份

- 每天的文件位于 `<日记根文件夹>/<年份>/<YYYY-MM-DD>.md`。附件位于同一根文件夹的 `assets/<年份>/<日期>/`。
- 在日记列表中右键某一天并选择“删除日记”，该 Markdown 文件会移入根文件夹的 `Trash/`；附件不会跟随删除。需要恢复时，请先确认目标日期没有同名文件，再移回对应年份文件夹。
- 备份时复制**整个日记根文件夹**，包含所有年份目录、`assets/` 和需要保留的 `Trash/`。迁移后在“设置 → 文件与存储”里重新选择新文件夹。

## 安装与更新

最新版本从 [GitHub Release](https://github.com/Yangsw0-0/Diary/releases) 下载。应用暂不自动更新；升级时下载新的安装包覆盖安装。旧 ZIP、旧安装程序和其他位置的应用副本需要自行清理，它们占用磁盘空间；退出旧应用后，它不会继续占用运行内存。

### macOS（Apple 芯片）

下载 ZIP，退出旧版 Diary，解压并将新的 `Diary.app` 放到旧版的安装位置，确认替换。安装包使用 ad hoc 签名、未做 Apple 公证；如果 macOS 阻止首次打开，请在“系统设置 → 隐私与安全性”中确认来源后放行。

### Windows（10/11 x64）

下载 `Diary_<版本>_x64-setup.exe` 并运行。安装按当前用户进行，不需要管理员权限；升级时直接运行新安装包覆盖旧版本。Windows 11 已内置 WebView2；Windows 10 缺少时，安装程序会联网下载运行时。安装包未做代码签名，SmartScreen 可能提示“未知发布者”；确认文件来自本项目仓库后，可选择“更多信息 → 仍要运行”。

覆盖安装或替换应用程序不会清除另行存放的日记和附件。平台矩阵、行为差异和源码分区说明保存在项目文档的《平台支持与源码分区》中。

## 存储目录兼容性

新建日记、导入附件及回收副本需要目录支持硬链接。不支持硬链接的 exFAT/FAT32 或部分网络目录会报告失败，应用保留当前草稿，不会把复制到一半的文件发布为正式日记。建议使用本机 APFS 或 NTFS 目录。

## 1.3.3 维护更新

本版改善相邻日记切换的边界回弹和编辑器就绪处理，操作方式不变。标签和写作统计共享有容量限制的内存解析缓存；不会创建额外索引文件，切换文件夹时清理解析缓存。升级仍需退出旧版并用新版 Diary.app 替换旧应用，日记目录保持不变。

## 节点：记录值得纪念的事件

左侧点击「节点」进入全宽画布。一个日期对应一个节点，同一天可以记录多条事件，每条包含时间概述（1–36 字）和颜色。节点数据保存在当前日记文件夹根目录 `Nodes.json`，与年份文件夹同级，不属于日记正文，也不计入写作统计。

右下角点击「添加事件」，填写日期、概述并选择颜色。相同日期会自动合并为同一个节点。轮盘条目双击或点击铅笔打开编辑弹窗，颜色也在弹窗中选择；修改日期会移动这条事件，不影响当天其他事件。删除需要再次确认；删除当天最后一条事件时，对应日期节点也会消失。

上方时间轴按日期由早到晚排列，间隔近似真实时间跨度。每个节点只在轴线上方或下方标注「月.日」，事件标题在另一端，日期与标题上下交替排布，并用一段虚线引线连回轴线；圆点较小、空心，聚焦时用事件颜色填充并带光晕。轴线上为每个跨年边界画一条短刻度，刻度左侧是旧年份、右侧是新年份；某一年没有事件也会保留前后两个刻度。轴起点标出第一年并连到「起点」圆环；最新端在轴线上写「to be continue…」，以箭头收尾。左右拖动或使用触控板横向手势浏览，松手后最近的事件会移到画面中央，并与下方指针指向的事件对齐；滚动停下后也会对齐。时间轴与轮盘之间是一条可拖动的细线：上下拖动改变两部分的高度，时间轴最小 120 像素，轮盘至少保留 220 像素；聚焦后也可用 ↑/↓ 微调，Home/End 到两端，高度会被记住。

下方轮盘只露出右侧一段：事件卡片像一笔刷出的色块，左侧、上下的浅色边界较窄，右侧拖出较长的渐隐笔锋，没有边框；卡片随轮盘转动，左侧长指针指向当前事件。卡片左侧是「月.日」，下面是字号略小的年份，中间一个分隔符，右侧是事件标题，铅笔图案固定在卡片右侧中部；标题最多三行。卡片宽度随窗口在 250–520 像素之间变化，变窄时标题自动换行，深色区域随之伸缩，右侧笔锋长度基本不变。向下拖看更早事件，向上拖看更新事件，松开吸附到最近条目；焦点附近最多显示九条事件。点击条目聚焦；轮盘获得键盘焦点后，↑/↓ 切换，Home/End 到最早/最新，Enter 编辑，Esc 关闭编辑弹窗。时间轴和轮盘共享焦点，焦点不写入文件，重启后默认聚焦最新事件。

事件颜色统一在铅笔编辑弹窗的六个色块中选择，点击立即生效。设置 → 个性化 →「节点颜色」可调整六槽色板或恢复默认；修改同一槽位会同步影响所有使用它的事件。色板仅保存在当前应用设置中，不写入 `Nodes.json`；换电脑需要重新设置色板。

右上角圆环表示保存状态：绿=已保存、黄=尚未保存、灰色脉冲=正在保存、红=失败；点击可立即保存。编辑后约 800 毫秒自动保存，保存过程中继续编辑会接着保存。切换模块、窗口失焦、关闭或更换文件夹会尝试保存；保存失败时草稿保留，关闭和换目录会阻止或要求明确放弃。离开节点模块不阻止导航，再次进入仍可看到错误和草稿。

若文件被其他软件修改，干净状态会重新载入，存在草稿时提示冲突。可选择「重新载入」（放弃当前节点草稿）或明确确认「覆盖保存」。遇到损坏或未知版本，不会自动覆盖；可先备份损坏文件并新建，备份留在原目录。首次进入且文件不存在时不创建文件，首次新增保存后才生成。最多 1000 条事件，文件上限 4 MiB。请将 `Nodes.json` 与日记、附件一起备份；节点暂不支持搜索、筛选和导入导出。

## 设置分类

设置采用两级布局：左侧选择分类，右侧显示该分类的具体设置。右侧内容可独立滚动，左侧分类始终可见；小窗口下选项会自动换行。

- **个性化**：浅色/深色外观、主题色、列表栏色调、节点六槽色板及恢复默认。
- **编辑与阅读**：正文行间距、字间距，以及重置排版。
- **文件与存储**：查看当前日记文件夹路径，或点击“更换文件夹”。切换前仍会保存日记与节点草稿。
- **帮助**：点击“打开使用说明”查看完整手册。

进入设置默认显示“个性化”。仅切换分类不会修改任何设置值；已有设置继续即时生效。键盘聚焦左侧分类后，可用↑/↓切换，Home/End到第一/最后分类，Tab进入右侧设置。顶部“返回上一页面”仍会关闭设置并回到原页面。
