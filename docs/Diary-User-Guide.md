# Diary 使用说明

Diary 用来写日记、按主题回顾生活、记录重要事件，以及探索经常出现或想要开始记录的话题。日记是 Markdown 文件，保存在你选择的文件夹中。可以从“设置 → 帮助”随时打开这份手册。

## 开始使用

1. 首次启动，点击“选择文件夹”，选择一个已经存在的日记根文件夹。应用不会自动创建或预选目录；取消后可以稍后再选。
2. 再次启动会继续使用上次的文件夹。目录被移动、删除或无法访问时，请重新选择。
3. 在左侧选择“日记”“标签”“节点”或“词云”。左下角“设置”可以更换目录、调整外观与阅读排版。

日记中的二级标题是正式标签：“标签”栏目汇集这些标题下的内容，“词云”显示这些主标签及你添加的话题。节点用于单独记录值得纪念的事件，不会自动改动日记。

## 界面与布局

- 最左侧是功能侧栏。拖动右边缘调整宽度；右下角按钮收起，收起后把鼠标移到窗口左边缘可临时唤出。
- 中间是列表栏：日记显示日期及当天主标签，标签显示主题分组。拖动右侧分隔线调整宽度，右下角按钮收起列表。过长文字省略显示。
- 右侧是内容栏，用于编辑日记或阅读标签内容；各栏独立滚动。节点和词云使用独立画布。
- 顶部“返回上一页面”“返回下一页面”可回到之前的栏目和阅读位置。设置页后退会先关闭设置。历史仅在本次运行中保留。
- 左下角写作统计显示已记录天数和累计字数，只计算当前文件夹已成功载入并保存的日记。未保存草稿不计入；标点计入，空白、Markdown 标记、首行日期和图片路径不计入。读取失败时数字可能不完整。

## 写日记与保存

1. 点击列表日期打开日记；点击“新建”打开或创建今天的日记。
2. 直接在正文编辑，标题、列表等会呈现渲染效果。可使用 Markdown 语法，如 `## 主题`、`**重要**`、`- 列表项`。
3. 停止输入约 800 毫秒自动保存。顶部圆点绿=已保存、黄=尚未保存、灰=保存中、红=失败。点击圆点或按 **⌘S**（macOS）/**Ctrl+S**（Windows）手动保存。
4. 修改正文首行日期并保存，会按日期更改文件名及年份目录。目标日期已存在时不会覆盖，请处理冲突。

段落旁“+”与拖动按钮用于块操作，大小随正文缩放；窄窗口下会纵向排列。在段落处右键可选择“插入插件”，插入图片或附件、分隔线、代码块或表格。

列表条目显示当天的主标签，以 `·` 分隔。例如 `探索自我 - 恋爱` 只显示 `探索自我`，同一天重复主标签只显示一次。

保存失败时保留草稿，可按提示重试、重新载入磁盘版本或明确确认覆盖。重新载入或放弃草稿会丢弃未保存修改，请先确认。应用不提供独立的全文搜索入口；通过日期列表、标签分组与词云浏览内容。

## 标签与分支

在日记中使用二级标题，例如：

```markdown
## 探索自我 - 恋爱

今天想到的事情……

## 探索自我 - 世界观

另一段记录……
```

`探索自我` 是主标签，`恋爱` 和 `世界观` 是可选分支，连字符两侧留空格。不写 ` - 分支` 时，整个标题就是主标签。正文普通提到的词语不会自动变成标签。

- 标签栏目按主标签归类；右侧分段显示日期和分支，点击日期跳回原日记的小节编辑。标签详情只读。
- 默认出现两天及以上的标签显示在上方，其他归入“隐藏的标签”。右键标签可“显示”或“隐藏”；两组都按出现天数从多到少、最近日期从新到旧排序。
- 输入 `## ` 并键入标签前缀后，可能出现浅色补全。**Tab** 接受，**Esc** 取消。
- 标签内容显示最后成功保存的版本。为分隔主题而留下的连续空行、单独的 HTML 换行标记不会形成大片空白；正常段落、列表、引用和代码保留。此处理不修改原日记。

## 阅读相邻日记

正文未到边界时，触控板和滚轮只滚动正文。到边界继续同方向滑动，会先出现弹性反馈，继续拉动则相邻日记预览进入内容栏。macOS 触控板跟随手指，松手未达到阈值时回弹，达到阈值则完成切换。鼠标滚轮以短暂停顿判断手势结束。

向上切到相邻日记时停在目标结尾，向下切换时停在目标开头；一次手势最多切换一篇。切换前检查保存，保存或打开失败时回到当前页。系统启用“减少动态效果”时会减少过渡动画。

## 附件与图片

点击“附件”选择文件，也可拖入文件或直接粘贴图片。单个文件须非空且不超过 20 MiB。

附件复制到日记根目录的 `assets/`，正文使用相对链接。图片可在编辑器与标签详情预览；普通附件链接由系统打开。删除正文链接不会自动删除附件文件。

## 节点：重要事件

点击“节点”进入画布，右下角“添加事件”填写日期、1–36 字的概述与颜色。一天可以有多条事件。双击事件或点击铅笔编辑；删除需要确认，删除当天最后一条事件会移除该日期节点。

上方时间轴按时间排列，标注完整日期。左右拖动或触控板横向滑动浏览，停止后最近事件居中，并与下方轮盘同步聚焦。拖动中间分隔线可调整上下区域高度；分隔线获得焦点后也可用 ↑/↓、Home/End 调整。

下方轮盘中，月日与年份位于虚线、实线两条弧线之间，事件正文位于实线外侧。日期与正文共用连续渐变卡片，沿各自半径一起旋转；实线旁的小圆点和短指针标识正文起点。弧线轮廓不动，虚线纹理与细微高光随轮盘同向运动，停止后一起减速停下。当前事件最清晰，其他事件按距离逐渐淡化，长标题最多三行，可悬停查看完整概述。

轮盘可上下拖动，也可用触控板双指上下滑动；斜向滑动只取上下分量，左右滑动不转动轮盘。自然滚动方向遵循系统设置。点击条目聚焦；轮盘获得键盘焦点后，↑/↓ 切换，Home/End 到两端，Enter 编辑，Esc 关闭弹窗。

颜色在事件编辑弹窗中选择。设置 → 个性化 → 节点颜色可调整六个颜色槽，同槽事件一起改变颜色。右上角保存圆点含义与日记相同，编辑后自动保存。

节点保存在当前根目录 `Nodes.json`，不写入日记，不计入写作统计。外部修改或保存失败时请根据提示重新载入或确认覆盖；损坏文件不会被自动覆盖。最多 1000 条事件；暂无搜索、筛选或导入导出。

## 词云：发现与开始话题

点击“词云”，中央球体可鼠标拖动或触控板双指上下、左右、斜向滑动旋转。前侧词语清晰，边缘渐淡，背面隐藏。拖动和点击是分开的，旋转不会触发写作。系统滚动惯性会延续旋转；鼠标拖动松手也有轻微惯性。

右侧输入自定义词语，按 Enter 或加号添加。首尾空格会被清理，相同自定义词不能重复添加；最多 500 个，每个最多 120 字符。删除只移除自定义来源，可在提示条撤销最近一次删除，不会删除日记标签。

“显示已有标签”默认开启，包括标签栏目中隐藏的主标签，分支不额外生成球面词语。关闭后隐藏纯标签词，但你自己添加过的同名词仍保留。词语身份保持稳定，同名标签出现后会自动归为标签词，不新增重复球面节点；自定义来源仍保留，方便撤销删除和切换显示。

### 颜色与使用频率

只统计正式二级标题，正文普通提到的词不计数。同一主标签在同一天多次出现也分别计次，分支归主标签统计。颜色由正式标签频次的排名决定：低频蓝灰、中频青绿、较高频暖棕、最高频暖红；深色模式使用相应浅色。尚未成为正式标签的自定义词降低透明度，仍可点击。

同频词使用相同颜色。计算方式为“频次不超过它的正式标签数量 ÷ 正式标签总数”；小于 20% 为低频、20% 至小于 50% 为中频、50% 至小于 90% 为较高频、90% 及以上为最高频。只有一个标签或所有标签同频时，均为最高频。标签保存更新后，颜色自动重算。

### 点击词语

- 点击已有标签词：进入标签内容页；同名自定义来源不改变这一行为。
- 点击尚未使用的自定义词：打开今天的日记，在末尾追加对应二级标题，并定位到内容区。今天不存在时创建，已有内容保留；已有相同标题时直接定位，不重复追加。保存失败仍打开草稿，使用编辑器的错误提示和重试控件处理；成功保存后才更新标签统计。含换行的词无法作为标题，会提示错误。
- 例如添加“科研”，点击它后开始写今天的 `## 科研`。保存成功后词云会将其作为正式标签统计。

### 显示与保存

右侧可开关缓慢自动旋转，选择经纬网格、星座连线、混合或关闭线条；右上角可收起管理面板。手动操作时暂停自动旋转。系统减少动态效果下不自动旋转且关闭额外惯性，仍可手动旋转。键盘聚焦球面后，方向键旋转，Enter/空格选择最前方可交互词；也可从右侧列表操作。过密词会临时避让，长词省略显示，悬停或列表可查看完整内容。

自定义词及显示配置保存在根目录 `WordCloud.json`，标签不另存副本。首次实际修改后自动保存，右上角圆点可手动保存；关闭、失焦、离开栏目或更换目录也会尝试保存。失败保留草稿；损坏文件或未知版本不会自动覆盖。外部冲突时可重新读取（放弃草稿），或明确确认覆盖。各日记文件夹的词云独立。

## 设置与阅读排版

设置左侧选择大类，右侧修改项目：

- **个性化**：浅色/深色、主题色、列表底色、节点色板及恢复默认。
- **编辑与阅读**：正文行间距、字间距和重置排版。
- **文件与存储**：查看完整路径、更换日记文件夹；切换前检查保存。
- **帮助**：打开本说明。

修改即时生效。左侧分类可用 ↑/↓、Home/End 切换，Tab 进入右侧。正文排版与主题保存在应用设置中，不改动 Markdown。

把鼠标移到日记或标签内容栏右下角可显示缩放条和展开按钮。缩放调整阅读字号；展开让内容占满应用，再次点击恢复布局。

## 删除、存储与备份

右键日记列表条目选择删除。删除会将日记及相关附件作为回收副本放入根目录 `Trash/`；恢复需手动确认目标无同名文件，再移回对应年份目录。

日记按 `<年份>/YYYY-MM-DD.md` 保存。备份时复制整个根文件夹，包含所有年份、`assets/`、`Nodes.json`、`WordCloud.json` 及需要保留的 `Trash/`。GitHub 程序仓库不会自动备份你的日记，也没有云同步。

建议使用本机 APFS 或 NTFS。新建文件与附件需要目录支持硬链接；exFAT/FAT32 或部分网络目录可能保存失败，此时应用保留草稿。外部工具也编辑同一文件时，请及时处理冲突。

## 安装与更新

从 [GitHub Release](https://github.com/Yangsw0-0/Diary/releases) 下载。应用没有自动更新；以后默认提供 macOS 更新，Windows 仅在另行发布时更新。

macOS Apple 芯片：退出旧应用，解压 ZIP，把新 `Diary.app` 放到原安装位置并确认替换。当前安装包为 ad hoc 签名、未做 Apple 公证；系统阻止首次打开时，请确认来源后在系统设置 → 隐私与安全性中放行。

Windows 10/11 x64：使用最近提供的 `x64-setup.exe` 按当前用户安装或覆盖升级；Windows 10 缺少 WebView2 时安装程序会下载运行时。未签名安装包可能出现 SmartScreen 提示，请核对来源。

替换程序不会清除单独存放的日记目录。旧 ZIP、安装程序和其他位置的应用副本占用磁盘空间，可自行清理；退出旧应用后不会继续占用运行内存。更新前仍建议备份日记根目录。
