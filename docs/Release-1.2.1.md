# Diary 1.2.1 更新记录

日期：2026-11-18。平台：Apple 芯片 macOS。

## 修复

- 正文未到边界时正常滚动；同一次滚动刚到边界的惯性不再触发翻页。
- 在顶部或底部再次滚动时，预览按占据内容栏的高度渐入；达到阈值并停止滚动后才切换，未达到阈值则退回。
- 同一次触控板/鼠标滚轮手势最多切换一篇日记。切换期间屏蔽余下惯性，仍保留原有草稿保存与失败阻止切换机制。
- 预览进度只更新合成层样式，避免每个滚轮事件都重新渲染 Markdown。
