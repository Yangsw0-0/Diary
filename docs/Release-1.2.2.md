# Diary 1.2.2 更新记录

日期：2026-11-18。平台：Apple 芯片 macOS。

## 编辑体验

- 段落旁的“+”和拖动按钮随正文缩放改变尺寸；内容栏变窄、左侧留白不足时会移到段落上方。调整栏宽或缩放时，旧位置的悬浮按钮会先隐藏，重新悬停后按新尺寸定位。
- 内容栏顶部工具栏在向下阅读时保持可见。保存按钮改为圆形指示灯：绿=已保存、黄=尚未保存、灰=正在保存、红=保存失败；点击可手动保存，原有 **⌘S** 仍可使用。
- 在正文段落中右键可打开“插入插件”菜单，从点击位置插入图片或附件、分隔线、代码块或表格。

## 相邻日记

- 从正文内部滑到边界时，正文正常滚动；抵达边界后同一次手势先出现弹性反馈，继续滑动便连续进入相邻日记的只读预览。停在阈值前会回弹，过阈值后以减速动画完成一屏位移。
- 当前页与预览页共用位移轨道，目标页边界在内容栏对齐后停止。取消、读取或保存失败时退回原页；每次手势最多打开一篇。减少动态效果时直接完成动画，但保留切换阈值。
