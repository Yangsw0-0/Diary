# 节点轮盘径向布局与轨道反馈

适用版本：macOS 1.8.1。数据格式、节点保存、上方时间轴和已有轮盘交互保持原样。

## 几何关系

`NodeWheelGeometry` 是唯一几何参数来源。中心为轮盘左边缘中点 C；现有代码的虚线半径较小、实线半径较大，因此按实际半径而非内外命名定义位置：

- 实线半径 R 根据内容区宽高计算，在220–760px之间；轨道带宽 B 限于104–148px。
- 虚线半径 R−B，日期中心半径 R−B/2，日期宽72px。日期左右端都留在两线之间。
- 统一事件卡片起点半径 R−B+10；正文起点 R+24。
- 指针从实线外2px开始，长16px，在正文起点之前结束。
- 卡片宽度 = 正文相对起点 + 剩余可用正文宽度（上限440px），右侧预留24px。正文另留铅笔空间，最多3行、按字换行，完整文字由悬停标题提供。

每项保持 `rotate(i × 16°) translateX(cardRadius)`，父级 rotor 旋转 `−position × 16°`。日期、正文和连接线都是该项的子元素，位置以本地径向偏移量计算，不分别投影屏幕坐标。连续渐变背景由统一事件容器的伪元素绘制，日期区淡、正文区略深；不通过扩大选中卡片影响间距。

## 固定轮廓、流动纹理

原固定CSS圆框替换为独立于rotor的SVG。两个circle的圆心与半径在旋转期间不变；实线基础轨道常驻，叠加低对比短高光，虚线使用3/8 dash pattern。

纹理偏移量为 `−angleRadians × radius`。SVG虚线正offset向路径反方向移动，因此此符号与卡片顺/逆时针方向一致。两个轨道纹理与rotor共用同一position、280ms ease-out；拖动和wheel输入期间同时关闭transition，直接跟随位置；松手吸附时同步减速。无自动循环、无需新增RAF，不额外模拟已有系统滚动惯性。

减少动态效果时同时关闭轨道、卡片及rotor过渡。配色只使用foreground、muted-foreground和节点色板变量；轨道覆盖层无指针命中，点击仍落到原卡片和铅笔按钮。

## 验证

- 自动测试：不同尺寸的日期边界、卡片宽度、连接长度；轨道半径固定与纹理位移的角度关系；正反向、直接拖动、纵向wheel、忽略横向wheel；原节点增删改存与编辑入口回归。
- 浏览器内存示例：亮/暗、520与760px内容宽度、长标题、顶部/中央/底部条目、键盘切换、铅笔编辑弹窗已检查。未读取真实日记或节点文件。
- 未完成原生macOS触控板物理设备手感及持续高频输入帧率测量；浏览器验证不代替原生验收。Windows本轮不打包、不验证。
