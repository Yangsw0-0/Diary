# Diary 1.1.0 更新记录

日期：2026-11-18。平台：Apple 芯片 macOS。

## 新增与调整

- 日记列表显示当天全部二级标题标签，以 `·` 连接并在窄列表内省略；不再使用首行主标题作为摘要。
- `## 主标签 - 分支` 按主标签聚合，详情每段右上角显示分支；原始 Markdown 不改写。二级标题输入前缀后显示淡色补全，按 Tab 接受，Esc 取消。
- 标签可右键显示或隐藏；原“仅出现一次”改名为“隐藏的标签”。两个分区都按出现天数、最新日期排序。
- 设置增加绿色、浅粉色、浅蓝色与自选主题色；浅色和深色界面共用颜色变量。
- 扩大右下缩放控件的悬停区域。日记末尾显示上一篇的淡化只读预览；在正文滚动边界继续使用触控板或鼠标滚轮，达到阈值后通过既有保存与导航流程切换相邻日期。中间列表选中背景平滑滑动，系统减少动态效果设置会关闭过渡。

## 安装与数据

退出旧版后，解压并将新的 `Diary.app` 放到原来的安装位置，确认替换。ZIP 不会自动覆盖旧 ZIP；其他位置的旧应用副本也不会自动删除，它们只占磁盘空间。退出旧版后旧进程不会继续占用运行内存。日记 Markdown 和附件仍在用户选择的日记文件夹；主题与标签显隐偏好保存在应用的本地设置中。此次不包含自动更新器。
