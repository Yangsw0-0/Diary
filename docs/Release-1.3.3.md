# Diary 1.3.3 更新记录

日期：2026-11-20。平台：Apple 芯片 macOS。

## 改进与修复

- 将相邻日记的滚轮、原生触控阶段、动画与取消逻辑从 AppShell 提取为独立 Hook，保持保存和导航接口不变。
- 标签索引和写作统计共享 Markdown 语法树缓存，按原文精确匹配；缓存有容量限制，切换文件夹时清理。
- 修复首尾边界拉拽锁住、手指未松开提前解锁，以及旧编辑器就绪通知影响新页面的问题。
- 新文件发布不再回退到可能留下不完整文件的直接复制。不支持硬链接的文件系统会报告失败并保留草稿；建议使用本地 APFS 日记目录。
