# Diary 1.6.0

节点画布的排版与时间轴细化版本，数据格式与 1.5.x 兼容。

## 本版内容

- 事件卡片左侧改为「月.日」在上、年份在下（年份字号更小），标题后不再有第二个分隔符，铅笔图案移到卡片右侧中部。
- 笔刷底色改为左、上、下窄边渐隐，右侧拉出较长笔锋；卡片宽度随窗口在 250–520px 之间变化，标题自动换行，深色区域伸缩而笔锋长度基本不变。
- 时间轴上节点只标注「月.日」，日期与事件标题上下交替，引线改为虚线；每个跨年边界增加年份刻度，左侧旧年、右侧新年，没有事件的年份也保留两个刻度。
- 重排轴起点年份、起点圆环与「to be continue…」，续页文字放在轴线末端并由箭头收尾。
- 时间轴与轮盘之间的分隔线可上下拖动，时间轴最小 120px、轮盘至少 220px；键盘可调，高度会被记住。
- 修复与维护：沿用 1.5.x 的节点保存、冲突、损坏恢复与中文错误提示；本次未改动 `Nodes.json` 格式。

## 验证

- 前端 `npm run check` 通过：格式、lint、110 项测试、类型检查与生产构建。
- Rust `cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test`（23 项）通过；Windows 目标 clippy 通过。
- macOS 应用以 ad-hoc 签名构建，`codesign --verify --deep --strict` 通过，未做 Apple 公证。
- Windows 安装包由 GitHub Actions 的 `windows-latest` 任务构建并上传；Windows 真机安装与窗口交互验收仍待完成。

## 已知限制

- macOS 包未公证，首次打开可能需要在系统设置中手动放行；Windows 包未签名，SmartScreen 可能提示“未知发布者”。
- 节点仍不支持搜索、按颜色筛选与导入导出；六槽色板保存在本机设置中，不随 `Nodes.json` 迁移。
- 轮盘卡片笔刷边缘与拖动惯性依赖系统 WebView 的模糊与遮罩实现，极端小窗口下的观感仍需实际窗口复核。
