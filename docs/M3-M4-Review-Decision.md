# M3/M4 结构审查处理记录

> 2026-11-17 · 根据用户提供的静态审查建议逐项核对；修改限于 Diary 项目。

| 建议 | 处理 | 原因与实现 |
| --- | --- | --- |
| 切换日期的异步读取可能覆盖旧稿 | 采纳 | 编辑会话增加过渡态；读取前后均等待保存，读取失败保留原日记与草稿。编辑器过渡期间只读，迟到的编辑事件仍由会话接收并在切换前保存。 |
| 冲突后无法离开或正常关闭 | 采纳 | 提供“重新加载磁盘版本”“覆盖保存”“放弃草稿”；关闭时若保存失败，显示“继续编辑 / 放弃草稿并关闭”。同日重载递增编辑器代次并重建编辑器。 |
| 增加无条件的 Rust overwrite 写入语义 | 不采纳 | 覆盖操作先读取当前磁盘 revision，再用现有 match/new 条件保存。外部文件若在确认后再次变化，仍返回冲突并保留草稿；无需开放跳过版本检查的写入路径。 |
| 错误携带当前 revision 等结构化详情 | 暂缓 | 当前恢复动作通过重新读取磁盘版本执行，不依赖错误中的 revision。若后续提供差异对比，再扩展错误契约。 |
| 焦点恢复与刷新时检查外部修改 | 采纳 | 干净草稿自动载入新版本；未保存草稿标记冲突并保留正文。 |
| M5 导航历史、模块 capture/restore、编辑器定位接口 | 留到 M5 | 需要与真实的标签跳转和滚动恢复一并设计。当前先补齐同日重新加载代次和适配器工厂；现在加入 unknown 视图状态会降低类型安全，且尚无可验证的导航行为。 |
| 全面拆分 DiaryService、DiarySession、TagService | 暂缓 | 本轮优先修复状态和数据风险。M5 的导航状态另设 NavigationHistory，不塞进编辑会话；对现有类的拆分应以实际稳定边界为依据。 |
| reset 隐式依赖 Provider 重挂载 | 采纳 | 根目录切换显式调用 resetAndLoad；Provider 的加载只负责首次挂载，重叠请求会合并。 |
| 标签详情批量读取、部分失败与取消 | 部分采纳 | 各日期读取并行执行；单日失败单独展示，其余日期继续显示；切换标签时阻止旧请求回写索引。暂不新增 Rust readMany IPC，避免在未测量瓶颈前扩张跨语言契约。 |
| 标签查询不应更新索引 | 暂缓 | 详情必须先核对 revision；发现外部改动时重建当天索引才能保证偏移有效。取消的请求不会修复索引，读取失败不会展示旧切片。 |
| 减少隐藏模块重渲染、缓存分组 | 部分采纳 | TagIndex.listGroups 按版本缓存结果；标题从解析摘要读取。完整 selector 拆分留待观察真实键入性能。 |
| 标题双实现与格式标记泄漏 | 采纳 | 日记列表使用与标签同一解析器生成的摘要，格式化标题显示可见文字；无标题时只显示日期。 |
| 文件已保存但索引投影失败造成假失败 | 采纳 | 保存结果与索引投影隔离；失败时清空并标记索引需要重建，界面提示刷新日记列表。 |
| 编辑器依赖具体 infrastructure 类 | 采纳 | 组合根注入 EditorAdapter 工厂，编辑器组件只依赖接口；适配器增加只读控制。 |
| TagOccurrence 字段迁出 domain、拆面板文件 | 暂缓 | TagOccurrence 当前是与 revision 绑定的不可变读模型，迁移文件位置没有改变行为；M5 确定导航引用后再分离稳定的 TagRef。面板拆分以导航实现时的职责界线为准。 |
| 隐藏日记页仍处理全局保存快捷键 | 采纳 | 快捷键只在日记面板可见时处理。 |

回归测试覆盖延迟读取期间编辑、读取失败保稿、冲突恢复动作、关闭失败后明确放弃、外部修改检测、部分标签读取失败、取消旧请求、格式化标题和保存成功后的索引故障。
