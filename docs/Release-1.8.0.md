# Diary 1.8.0：词频、快捷写作与触控板操作

日期：2026-11-23。本次仅发布 macOS Apple 芯片安装包；Windows 保留 1.7.0。

- 帮助按实际功能重写为使用手册，移除开发过程与版本日志。
- 词云按正式二级标题出现次数的排名分四级着色，同频同色；未使用自定义词降低透明度。自定义词成为标签后保持同一显示身份，保留持久化来源。
- 点击未使用词可打开或创建今天的日记，追加标签并聚焦正文。已有正文逐字符保留，同名标签不重复创建；保存失败保留草稿，未闭合代码/HTML 阻止插入。
- 标签详情在显示层清理装饰空行和 HTML 换行，保留普通段落、列表、引用、代码与转义文字，不改原文。
- 词云支持双指二维滑动旋转；节点轮盘取垂直滑动旋转。复用现有旋转模型，局部非被动监听、归一化增量，避免页面误滚动和重复惯性。

数据文件格式不变，无需迁移。词频和当前类别由统一标签索引派生，不重复持久化标签；保留自定义来源便于删除撤销与显示开关。

发布规则：以后默认只更新 macOS；Windows 构建须明确请求，并通过手动工作流开启。本地每次保留 macOS ZIP 与校验摘要，不自动清理历史版本。

验证：前端 143 项测试、类型检查、格式检查、lint 与生产构建通过（保留既有 lint/包体积提示）；Rust 26 项测试、fmt 和严格 clippy 通过。macOS 版本 1.8.0、arm64 架构、ad hoc 签名、ZIP 完整性与包内文件均已核对。未访问真实日记数据。触摸板真实设备手感需要用户复核；自动化事件测试不等同于原生手势验收。
