## 已知限制

- 安装包未做 Apple 公证，首次打开可能需要在 macOS「隐私与安全性」中手动放行。
- 只提供 Apple 芯片 macOS 安装包；Windows 适配和旧单文件导入不在本版范围。
- 删除日记会移动文件至所选根目录的 `Trash/`，不会删除附件。用户需单独备份整个日记根目录。
