# Diary 1.4.0：节点时间轴

日期：2026-11-21。

- 新增与日记、标签并列的全宽「节点」模块，上方时间轴、下方可拖动事件轮盘，点击与键盘聚焦联动。
- 一天一个日期节点，一天可以包含多条独立事件；添加、修改日期、颜色与删除均支持。当天最后一条事件删除后移除空节点。
- 设置提供六槽自定义色板与恢复默认；同槽所有事件即时同步。色块仅在聚焦/悬停时显示。
- 节点存入日记文件夹根目录 `Nodes.json`，不修改Markdown正文；800毫秒自动保存、手动保存、外部修改冲突保护及损坏备份恢复。
- 帮助中新增完整节点操作说明；日记与节点复用保存指示器，保存和导航逻辑保持分层。

验证：前端107项测试、类型检查、格式、lint与生产构建通过（仍有既有lint警告）；Rust23项测试与严格clippy通过。节点真实窗口拖动手感和Windows真机尚未完成人工验收。CI编译、测试与安装包完整性不能替代人工验收。

macOS采用ad hoc签名，未做Apple公证。退出旧版后用新的Diary.app替换旧应用；日记目录不变。首次浏览节点不创建文件，首次实际保存创建Nodes.json。未知格式不自动覆盖；请将Nodes.json与日记、附件一起备份。
