# Diary 1.3.1 更新记录

日期：2026-11-18。重点平台：Apple 芯片 macOS。

## 改进

- 深色主题下选中的正文使用清晰的蓝色高亮和白色文字。
- macOS 触控板相邻日记翻页改用 AppKit 的实际触控阶段判断松手；手指停在边界拉拽中途时保持当前位置。普通文档滚动仍交给 WebKit。
- 向上翻到较新的日记后停在其结尾，向下翻到较早的日记后停在开头；编辑器自动把光标放在相应边缘，并在编辑器就绪后恢复精确滚动位置。
- 设置新增独立的中间列表色调、正文行间距和字间距；日记列表只显示主标签，不显示 ` - 分支`，同一天重复主标签仅显示一次。
