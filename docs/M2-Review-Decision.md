# M2 代码审查建议处理记录

依据用户提供的 M2 只读审查，对建议作如下取舍。本页记录实现边界，避免把 M3 的编辑能力误记为已完成。

| 建议 | 处理 | 原因 |
| --- | --- | --- |
| 同步 Tauri 文件命令阻塞主线程 | 采纳 | `list/read/save/get_workspace_status` 改为异步命令，阻塞文件操作进入 `spawn_blocking`；读写锁允许并发读取，切换目录等待在途操作，保存另行串行。 |
| 日记 Provider 切页卸载 | 采纳 | 两个模块保持挂载，仅隐藏非当前面板；已选日期和只读预览跨功能页保留。M3 的草稿与保存队列另放在独立编辑会话中。 |
| 保存与读取的首行日期规则不一致 | 采纳 | 首行必须是匹配文件名的 `# YYYY-MM-DD`，非法正文在创建年份目录前拒绝；旧坏文件仍留在原处并报告。 |
| `DiaryDate` 类型与 IPC 错误细化 | 采纳 | 日期抛出 `invalid_date`，运行时私有且可序列化；结构化 `unexpected` 错误保留后端消息；读取失败清除旧预览。 |
| 模块注册表只读消费接口 | 采纳 | 外壳只接收 `ModuleCatalog`，注册方法仍由组合根调用。 |
| 跨语言夹具与生命周期测试 | 采纳 | 扩充日期、版本期望和错误夹具，并验证切页状态、首行拒绝、CRLF 读取与并发目录切换。 |
| 立即实现 `DiarySession`、草稿和保存队列 | 延至 M3 | 当前只有只读预览，没有真实草稿。M3-04 与 M3-06 明确要求跨页会话和换根目录守卫。 |
| 立即拆分全文扫描与摘要接口 | 延至 M4 前评估 | M4 索引仍需要完整 Markdown；先根据真实归档大小决定是否增加摘要扫描或流式接口，避免提前维护两套扫描契约。 |
| 立即拆分所有 Rust 文件、增加错误枚举与 `createApp` options 对象 | 暂不采纳 | 现有模块职责仍可辨认，错误码由共同夹具约束，组合根只有两个可选依赖。继续增长时再拆分。 |
| 为闭包里的固定 `service` 增加 React effect 依赖 | 不采纳 | `service` 在 `createDiaryPanels` 时绑定，组件重渲染不能更换它；加入依赖会触发 hooks lint 的无效依赖告警。 |
| 立即接入暗色主题切换 | 延后 | 当前未承诺暗色模式；保留语义 token 供后续主题实现，不把变量存在当成已支持切换。 |
