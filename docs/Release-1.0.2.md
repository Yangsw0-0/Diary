# Diary 1.0.2 修订记录

日期：2026-11-17。平台：Apple 芯片 macOS。

## 修改

- 中间列表最小宽度改为 168px，窄列表的标题和操作按钮仍能完整显示。
- 拖动中间分隔线时停止网格过渡，让边界与鼠标同步；松开后保留折叠动画。
- 日期和标签条目由父列表约束宽度，长标题在条目内省略；完整标题仍可从提示中查看。
- 日记与标签详情各自记住缩放值。控件作为详情面板的一部分位于右下角，鼠标移入角落或键盘聚焦时渐显；标签页也可展开详情。
- 左侧标志和导航项补充宽度约束，避免窄侧栏时内容溢出。
