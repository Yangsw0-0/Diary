# Diary 交互与标签迭代：实施提示词与验收规划

> 历史交互计划：1.9.0已移除本文中的相邻日记滑动切换。当前写作与滚动行为见[打字机模式](./Typewriter-Mode.md)及[使用说明](./Diary-User-Guide.md)。


## 可执行提示词

在现有 React/TypeScript + Tauri 分层架构内，完成以下功能。仅修改 Diary 项目目录，不读写真实日记；保留既有 Markdown 文件格式、原文和路径。先补充纯领域对象与应用服务，再接入 UI 和设置持久化。每项完成后运行类型检查及相关测试，最后检查 Git 文件列表并推送。

1. 日记列表保留日期，把摘要改为该日二级标题标签，按原文顺序以 `·` 相连；无标签时只显示日期。内容超宽时单行省略。
2. 用 `TagName` 值对象解析 `xx - yy`：仅第一个带两侧空格的连字符分隔主标签与分支；缺少合法分支时保留整个标题。归类键为 NFC 规范化后的主标签，原文标题不改。标签列表显示主标签；详情按日期、原文顺序展示，每段右上角与日期平齐显示分支。重复主标签仍以 ordinal 精确定位。
3. 编辑器中的二级标题输入首字后，根据既有标签标题匹配前缀，在光标后显示不进入文档的淡色补全；Tab 接受，Esc 取消。中文输入法合成期间不抢键，普通 Tab 与非标签内容保持原行为。
4. 标签显隐状态由独立的 `TagVisibility` 管理并持久化到应用设置。默认出现两天及以上为显示，一天为隐藏；右键可互换。两个分区均按出现天数降序、最新日期降序、名称稳定排序。分区名为“隐藏的标签”。
5. 扩大缩放控制的悬停热区，保持渐显和失焦渐隐。
6. 外观设置支持浅色绿、浅色粉、浅色蓝及自选主题色。颜色输入经过验证，并通过统一色彩对象生成 CSS 变量，覆盖侧栏选中态、按钮强调色和编辑器主题；浅色与深色均保持可读对比度。
7. 日记正文边界支持触控板和鼠标滚轮的额外滚动量触发相邻日期切换：末尾向下到上一篇，开头向上/下的方向按用户语义核对，预览只读且淡化；未达到阈值时回弹。切换使用现有导航和保存检查，失败时保留当前文档。中间列表选中背景平滑位移。尊重系统“减少动态效果”。

## 数据与接口

- `TagName`：`parse(raw) -> { key, branch, displayTitle }`；不改写 Markdown。
- `TagIndex`：按主标签索引；提供 `getDayLabels(date)`、`getCompletionCandidates(prefix)`、按显隐和排序后的 `listGroups()`。
- `TagVisibility`：`isShown(key, dayCount)`、`setShown(key, bool)`；设置与日记数据分离。
- `ThemePalette`：验证十六进制颜色，并计算统一色板；由设置持久化，不写入日记目录。
- `AdjacentDiaryNavigator`：仅处理边界滚动的阈值、方向和冷却；真正切换调用既有 `openDiary`。

## 手势依据与保护条件

Apple 的 [Scroll views 指南](https://developer.apple.com/design/human-interface-guidelines/scroll-views)要求保留系统滚动手势和弹性反馈，并提示避免同向嵌套滚动。Web 的 [WheelEvent 文档](https://developer.mozilla.org/en-US/docs/Web/API/WheelEvent)指出滚轮事件不能直接等同于实际滚动方向；因此只在正文容器确实处于边界时累计额外 `deltaY`，并标准化 `deltaMode`。通过阈值后调用原有导航，不能绕开未保存草稿检查。预览采用相邻日记的只读片段，不挂载第二个编辑器。

## 验收清单

- 同日多个标签按顺序显示，列表宽度变化时不溢出。
- `探索自我 - 恋爱` 与 `探索自我 - 世界观` 同组，详情分支和原日记跳转正确；无分支标题正常。
- 中文输入法、Tab 补全、撤销、保存后原始 Markdown 正确。
- 右键显隐重启后仍在正确分区，排序符合出现天数与日期。
- 三种浅色主题和自选颜色在列表、设置、标签、编辑器一致；深色仍可用。
- 缩放条在可见区域上方均可触发；键盘可聚焦。
- 长日记仅在真正边界触发；未达阈值回弹；保存失败不切换；前后历史与列表选中态一致。

## 安装与存储说明

下载的新 ZIP 不会自动覆盖旧 ZIP。把新版本 `Diary.app` 放到旧版本同一路径并确认替换，应用程序文件才会覆盖；旧 ZIP 或其他位置的 app 副本仍占磁盘空间，需自行删除。退出旧版后它不再占用运行内存。日记保存在用户选择的文件夹，应用设置保存在 macOS 的应用配置目录，替换 app 不会清除这些数据。本迭代不引入自动更新器。
