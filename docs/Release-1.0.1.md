# Diary 1.0.1 修订记录

日期：2026-11-17。平台：Apple 芯片 macOS。

## 修改

- 左侧导航整块向左滑出，列表底部提供折叠按钮；窄列表将操作按钮排到标题下方，并限制列表宽度。
- 标题栏只显示所选日记文件夹名，完整路径保留在提示中。
- 正文宽度固定为右侧面板的 80%；缩放通过编辑器字体尺寸实现，避免 CSS `zoom` 造成的光标错位。
- 附件经二进制 IPC 传输；插入请求只消费一次；损坏的侧栏宽度不阻止启动。
- 标签图片状态按链接隔离，网页与邮件链接经系统打开；附件预览按同一文件句柄限量读取。
