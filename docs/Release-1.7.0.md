# Diary 1.7.0：球形词云

日期：2026-11-23。

- 新增与日记、标签、节点并列的「词云」栏目，支持自由拖拽、松手惯性与缓慢自动旋转。
- 球面文字具有前侧清晰、边缘渐淡、背面隐藏的纵深效果，提供经纬网格、星座连线、混合模式和关闭线条。
- 支持自定义词添加、删除和撤销；标签动态同步、按文本去重并保留独立来源。点击标签词可进入现有标签内容页。
- 可收起管理面板扩展球面，支持亮暗主题、高DPI、键盘和减少动态效果；尺寸变化后立即补画，避免闪空。
- 自定义词与显示配置保存在日记根目录 WordCloud.json，标签不复制存储。800毫秒自动保存，支持冲突提示与草稿保护。

自定义词上限500个，每词最多120个Unicode字符，文件上限512KiB；标签数量不受500个限制。备份时请将WordCloud.json与日记和附件一起复制。已有日记与节点格式不变，无需迁移。

验证：前端130项测试、类型检查、格式、lint和生产构建通过（仍有既有lint/构建体积提示）；Rust26项测试与严格clippy通过。浏览器内存示例已检查亮暗主题、拖拽、标签跳转、管理面板及窄窗口。原生双平台手工交互和超大真实词集帧率仍待实机验收。

退出旧版后，macOS解压并替换原位置的Diary.app；Windows运行新安装程序覆盖安装。macOS为ad hoc签名、未公证；Windows安装包未签名。应用不提供自动更新。
